FemtoLab Backup

Secure Backup and Data Recovery

About the Application

FemtoLab Backup is a utility for securely backing up and recovering authorized laboratory and project data using Google Drive.

How It Works

The application uses Rclone to transfer encrypted backup files to Google Drive. It is intended for authorized administrative use and disaster recovery.

Data Security

Backup contents are encrypted before being uploaded. Google Drive authorization is controlled by the account owner.
