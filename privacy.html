FemtoLab Backup

Privacy Policy

Last updated: November 18, 2026

1. Purpose

FemtoLab Backup is an administrative utility used to create, transfer, and restore authorized encrypted backups through Google Drive.

2. Google Drive Access

The application requests Google Drive access with the authorization of the account owner. This access is used to upload, list, download, and manage backup files.

3. Data Processing and Security

Backup files are encrypted locally using Rclone Crypt before being uploaded to Google Drive. Authorized administrators manage the encryption credentials separately.

4. Data Sharing

FemtoLab Backup is intended for authorized administrative use. The application does not sell Google user data or use Google Drive information for advertising.

5. Data Retention and Deletion

Backups are retained according to the administrator's backup and retention policies. Authorized administrators may delete backup files from Google Drive.

6. Access Revocation

Users can revoke the application's access through their Google Account security settings.

7. Contact

For questions about this privacy policy, contact the administrator using the support email provided on the Google OAuth consent screen.
